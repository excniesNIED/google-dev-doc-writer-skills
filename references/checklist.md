# Self-Correction Checklist

Run this checklist before delivering any document.

1. Did I use "we", "our", "I", or "let's"? Replace with imperative verbs or "you".
2. Are "If / To / When" conditions placed at the end of sentences? Move them to the front.
3. Are UI buttons in code tags? Change them to bold.
4. Are code samples self-contained and free of pseudo-code ambiguity? Use realistic variable names and complete payloads.
5. Are headings sentence case and action-starting?
6. Is the voice active and present tense?
7. Does the document follow the mandatory structure in document-structure.md?
